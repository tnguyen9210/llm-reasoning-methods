# Question Examples Data

This folder contains math question examples for PRM scoring experiments.

Each example uses the `reasoning steps` field and ends with a boxed answer, for example `The final answer is \boxed{42}.`.

## Files

- `question_examples.json`: pretty-printed JSON array.
- `question_examples.jsonl`: strict JSONL, one JSON object per line.
